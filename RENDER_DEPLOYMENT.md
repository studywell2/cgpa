# Deploying GCPA Calculator to Render

Render is a modern cloud platform that supports PHP/Laravel applications with a free tier available.

## Prerequisites
- Render account (free tier available) - Sign up at https://render.com
- GitHub repository with your code
- Your project files should be pushed to GitHub

## Steps to Deploy

### 1. Push Your Code to GitHub
1. Initialize git if not already done: `git init`
2. Add all files: `git add .`
3. Commit changes: `git commit -m "Initial commit"`
4. Add remote repository: `git remote add origin YOUR_GITHUB_REPO_URL`
5. Push to GitHub: `git push -u origin main`

### 2. Connect Your GitHub Repository
1. Go to https://render.com and sign in
2. Click "New" → "Web Service"
3. Connect your GitHub account and select your GCPA repository
4. Choose the branch you want to deploy from (usually `main`)

### 3. Configure Build & Deploy Settings
Use these settings in the Render dashboard:

**Runtime:** PHP
**Build Command:**
```bash
composer install --no-dev && npm run build
```

**Start Command:**
```bash
php artisan serve --host=0.0.0.0 --port=$PORT
```

**Instance Type:** Free

### 4. Set Environment Variables
In your web service settings, add these environment variables:

```
APP_NAME=GCPA Calculator
APP_ENV=production
APP_DEBUG=false
APP_KEY=(will be auto-generated by Render or use your existing key)
APP_URL=https://your-app-name.onrender.com
LOG_CHANNEL=errorlog
LOG_LEVEL=debug
```

For a simple CGPA calculator that doesn't require a database, you can use SQLite (default in .env.example).

### 5. Deploy
1. Click "Create Web Service"
2. Render will build and deploy your application automatically
3. Your app will get a URL like `https://your-app-name.onrender.com`

## Alternative: Using render.yaml
A `render.yaml` file has been created in your project root. This allows Render to automatically configure your deployment when you connect the repository.

To use it:
1. Ensure `render.yaml` is in your repository root
2. Push to GitHub
3. Connect repository in Render
4. Render will automatically read the configuration

## Notes
- Render's free tier includes 750 hours of runtime per month
- Your app will sleep after 15 minutes of inactivity on the free tier
- Auto-wake on first request after sleeping (may take ~30 seconds)
- Automatic deployments when you push to your connected branch
- Your app uses SQLite by default (no separate database needed)

## Troubleshooting
- Check the build logs in Render dashboard if deployment fails
- Ensure all environment variables are set correctly
- Verify that `composer.json` and `package.json` are properly configured
- Make sure your PHP version is compatible (requires PHP ^8.2)
